# Caixa eletrônico C
Caixa eletrônico desenvolvido em C, com saldo inicial de R$ 1.000,00. O programa valida o valor solicitado, verifica saldo e múltiplo de R$ 5, calcula as notas necessárias e informa possíveis erros. O projeto pratica lógica de programação, variáveis, operadores e estruturas condicionais.
